# Maester CLI

Implemented Python application. Provides `maester` and the compatibility command `pdf-financial-qa`, both with `ingest`, `ask` and `list-docs`.

Run from the repository root. See [development instructions](../../docs/DEVELOPMENT.md) and the [root quick start](../../README.md). Reusable document logic lives in `packages/financial-engine`; this application owns terminal presentation and command arguments.
