# Frequent replacements

This list is not the ASD-STE100 dictionary. It holds words that writers use often in software documents, with a plain replacement in the STE style. The dictionary (free on request from <https://www.asd-ste100.org>) is the authority. Where a replacement here and the dictionary disagree, use the dictionary and fix this file.

`scripts/ste-check.mjs` reads the table below. Keep one entry for each row: the word or phrase in the first column (lower case), the replacement in the second.
